## Production safety and verification

The existing course workflow uses one 256 MB machine and its original `/data` volume. Its preflight creates a private SQLite backup on that volume, checks integrity and foreign keys, and independently rechecks its hash before deployment. No database artifact is uploaded. A failed check or backup stops the release. The release image is tagged with the exact source commit and workflow run; the final confirmation checks the running image and integrated health.

The approved preflight completed successfully in [run 40208741107](https://github.com/comp4020-agentic-coding-studio/comp4020-final-ray0766/actions/runs/40208741107), before the main push. The private 3,674,112-byte snapshot reported schema 17, integrity `ok`, zero foreign-key violations, and an independently matching SHA-256. The successful main run also took and verified a snapshot immediately before deployment.

The observed production schema 17-to-20 compatibility path adds trip, appearance and first-character side tables. The migration preserved existing player rows and completed progress; old identities were not enrolled in first-character creation. The store also takes its own consistent backup before migration. This migration did not replace production with a test database or enable paid production AI.

Post-deployment Chrome checks used separate synthetic identities at 1920×1080 and 390×844. First-character creation, guide navigation, automatic travel, an owner update observed by a visitor without reload, a refused visitor write, saved appearance/objects on refresh and brief offline recovery passed across the recorded initial and follow-up runs. The first harness attempt stopped on an invalid returning-welcome assumption; the follow-up completed the remaining flow with the same identities. These were agent-driven tests, not ordinary-human usability approval. No provider call was sent; production AI remained off.

A separately confirmed, one-time maintenance reset followed at 18:26 UTC on 25 October. A consistent recoverable backup and restore rehearsal preceded deletion of the authorised player progress. Actual next-day persistence after this reset has not yet been demonstrated. Same-session refresh, isolated process restart and release/migration evidence must not be described as that elapsed-day test.

Physical-phone performance, other browser engines, arbitrary user buildings and long-duration production load are not certified. No HD grade or flawless experience is promised.
