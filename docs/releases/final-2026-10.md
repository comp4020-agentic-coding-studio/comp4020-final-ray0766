## Production safety and verification

The existing course workflow uses one 256 MB machine and its original `/data` volume. Its preflight creates a private SQLite backup on that volume, checks integrity and foreign keys, and independently rechecks its hash before deployment. No database artifact is uploaded. A failed check or backup stops the release. The release image is tagged with the exact source commit and workflow run; the final confirmation checks the running image and integrated health.

The approved preflight completed successfully in [run 40208741107](https://github.com/comp4020-agentic-coding-studio/comp4020-final-ray0766/actions/runs/40208741107), before the main push. The private 3,674,112-byte snapshot reported schema 17, integrity `ok`, zero foreign-key violations, and an independently matching SHA-256. The main release takes and verifies another snapshot immediately before its own deployment.

The observed production schema 17-to-20 compatibility path adds trip, appearance and first-character side tables. Existing player rows and completed progress are preserved; old identities are not enrolled in first-character creation. The store also takes its own consistent backup before migration. There is no permission to replace production with a test database, erase post-release data, or enable paid production AI.

Post-deployment verification is bounded to health, served build/README identity, key links, production AI-off status and representative desktop/narrow flows using separate synthetic verification identities. Any shared-state timings or persistence results from that stage must be identified as production observations rather than copied from the local report. The final delivery supplies the exact main SHA and successful check/deployment URLs, or reports an actual failure instead.

## Remaining boundaries

Abrupt wall cutaway and some close-doorway camera positions remain visual limitations; they were not redesigned during release. Physical-phone performance, other browser engines, arbitrary user buildings and long-duration production load are not certified. No HD grade or flawless experience is promised. This release approval is specific to this version, not standing permission for future production changes.
