# Direct reference observation — 2026-10-05

The live https://messenger.abeto.co/ was opened in the user's Mac Chrome, and its
WebGL world rendered successfully. The Begin screen, opening dialogue and normal
play view were observed. Short forward-key input was tried. No models, textures,
audio, shaders, or game source were downloaded/extracted.

## Confirmed differences

1. Messenger starts with a dense whole-world view, then moves to a close third-
   person camera. Its player occupies a substantial part of the play view. Little
   Post v1 retained a distant globe view during play and the character was tiny.
2. Reference streets are framed by buildings, stairs, signage, wires, vegetation
   and everyday props. Its shape reads as several connected places. V1 mostly had
   repeated trees and rocks across one plain-coloured spherical surface.
3. Reference silhouettes have dark drawing-like edges, flatter light/shadow
   regions, stronger value separation, and distinct foreground/background layers.
   V1's bright physically shaded palette washed together.
4. Reference dialogue gives a character and message visual focus. Its normal UI
   is very small. V1 kept a large editorial heading and a full mission card on screen.
5. The current local saved visit showed the courier hidden behind a tree. A closer
   camera still needs explicit occlusion handling, not only different numbers.
