## Fixed help and authorised AI trial

Topic buttons in **Fixed help & ground directions** remain documented local instructions. They are separate from free-text chat and never substitute for a model reply.

The authorised production configuration supports model access; the panel uses **Send to DeepSeek**, using `deepseek-flash` with thinking disabled and streaming. The visible disclosure explains that an explicit question sends only that question and public gameplay instructions to DeepSeek. It sends no conversation history, saved worlds, player identity or private messages. The model has no game tools and cannot change permissions or state. Every valid submitted question uses the model when enabled, including general conversation. Unknown game mechanics are not invented. Failed, stopped or limited calls show an explicit status and preserve the draft/partial answer instead of inserting fixed text. Fixed help remains separately available on the left. The right-side transcript stays in this page only; earlier messages are not sent as context. Both panels have independent close controls. On narrow screens help is above and chat below, leaving world space between them.

The server validates the existing cookie identity, then atomically reserves one of 8 attempts per rolling 60 minutes and a conservative share of a persistent US$1 trial budget. Tabs share the allowance and restart preserves it. Invalid/empty questions and refused duplicate requests do not consume a call. An attempted upstream request counts even if it fails or the player stops it. The interface shows remaining attempts, earliest slot recovery and approximate budget remaining. Calls stop if another reservation cannot fit, or at the authorised trial end: 1 January 2027, 00:00 Australia/Sydney (UTC+11; 31 December 2026, 13:00 UTC). Future calls use twice the peak rate verified on 25 October as conservative accounting headroom, not a promise of December supplier prices. Historical request charges remain unchanged. Clearing cookies can create a new identity; this is not absolute abuse prevention. The global budget is the backstop.

`GET /api/guide/status` returns non-secret availability; `POST /api/guide/ask` streams bounded replies. The existing `/api/guide/help` fixed/mock boundary remains. Default server configuration is AI-off. The explicitly authorised production backend now uses the server-side credential and the original transferred trial ledger; local paid access is retired.
