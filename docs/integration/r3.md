# R3 local integration

Base: physics `4c18ae5`. Module source:
`a4546bb120d969774776f1fbe2cb1c990a7c3e66`. Ten vendored files were updated and
`style/practical.ts` was added. All 32 source files match that commit byte for byte;
the build adapter in `vite.config.ts` changes resource URLs without editing the
vendored code. `PROVENANCE.json` records source and asset hashes.

Stage now owns workshop practical lights. The fixed workshop PointLight and
exposure/environment/fill overrides were removed. One medium pool in the main
scene supplies two spots and two points, with no practical-light shadow; it is
updated before rendering and survives per-planet scene replacement. Per-building
lamps were removed and colony ghosts are excluded. The existing harbour sun/fill,
custom service.light geometry and all physical envelopes remain unchanged.

`WorkshopView.bounds()` and `Stage.frameBox()` fit the actual canvas, retaining
empty-blueprint and current-plane bounds. Main's controls occupy separate grid rows,
so canvas overlay insets are zero. Pointer tracking suppresses pinch-as-placement;
a cancelable canvas touchend suppresses synthetic clicks. The demo's full event
system and Place/Cancel overlay were not copied.

The disposal update recognises the main application's `sharedResource` flags.
Building handles keep their existing disposeOwned chain; Stage releases its own
pool, library and context on close. Removing a building must not dispose the main
world's shared palette or texture library.

## Resource delivery

All 124 current module resources, including both map formats, manifest, HDRs and
transcoder JS/WASM, use `assets/claude/<full commit>/`. Immutable caching applies
only to such version URLs. Other assets and HTML use no-cache with ETags; matching
validators receive 304. Existing unversioned URLs are retained for older pages.
Future resource updates must use a new directory and keep the old namespace while
clients can reference it. Static MIME includes WebP, KTX2, WASM, JSON and HDR.

Medium 512 px colour/normal and 256 px packed maps remain the default. An explicit
`?textures=ktx2` exercises compressed delivery at the same detail level, including
per-map WebP fallback. KTX2 is not a smaller download: Claude's high blueprint
measurement was 2.46 MB WebP versus 14.17 MB KTX2. Its 22 MB compressed metric sums
transcoded mip payloads; the 88.1 MB WebP figure estimates RGBA8+mips. Neither is a
measurement of total physical VRAM. BC7 and physical phones remain unmeasured here.

No database migration is part of R3. A consistent local schema-6 backup was saved
before integration at `.data/before-r3-v6.sqlite`; it is private and ignored.
The published repository and Crit 8 evidence were not changed. The isolated module
suite's two existing medium scene-budget failures (251,369 > 250,000 triangles)
remain Claude's known issue and are not reported as green local checks.
